# Qué No Se Necesita (Descartado)

## Features Descartadas
- Firebase Auth y Realtime DB / Firestore.
- Rama experimental `agente-temporal` (abandonada como remota en origin).

## Razón
- **Firebase** fue descartado en los commits iniciales ("borron y cuenta nueva", "usencia de firease") para abrazar una arquitectura robusta Full-Stack relacional PostgreSQL, necesaria para el control absoluto de los números (Ver [[06-Historial-Decisiones|Historial]]).
- **`agente-temporal`** es un experimento previo abandonado antes de la implementación actual del agente LangGraph definitivo ([[03-Agentes-IA|Agentes IA]]).
