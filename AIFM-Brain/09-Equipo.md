# Equipo y Metodología

## Metodología
- Uso de convenciones de ramas (`feature/`, `fix/`, `chore/`).
- Se requieren **Pull Requests** para fusionar a `main` y asegurar compilación limpia en Turborepo.
- Linting estricto (uso de `pnpm lint`, `pnpm type-check`).

## Roles
- **Tech Lead / DevOps**: Arquitectura, CI/CD, configuración de Turborepo.
- **Backend Expert**: Modelado SQL, endpoints FastAPI, agentes inteligentes.
- **Full-stack**: Integración API-Frontend.
- **Frontend UI/UX**: Componentes (Next.js) y diseño visual (Tailwind CSS).
